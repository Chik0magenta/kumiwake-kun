# Kumiwake-kun v0.1 — 組み分けくん

일본어 회화 수업을 위한 무작위 그룹 편성 도구입니다. 공식 영문명은 **Kumiwake-kun**, 일본어명은 **組み分けくん**, GitHub 저장소명은 **kumiwake-kun**입니다.

## 실행과 사용 방법

별도 설치나 빌드 없이 `index.html`을 브라우저로 여세요. Vanilla HTML/CSS/JavaScript만 사용하며 외부 라이브러리가 없습니다.

1. 기본 일본어 UI에서 학생 이름을 한 줄에 한 명씩 입력하거나 UTF-8 `.txt` 파일을 선택합니다.
2. **名簿を反映 / 명단 적용**을 누릅니다. 파일 선택은 입력란만 채우며 적용 전 내용을 확인·수정할 수 있습니다.
3. 결석자를 눌러 제외합니다. 전원 출석·결석도 가능합니다.
4. **グループ数 / 조 개수**를 설정합니다. 기본값은 6이며 주로 6 또는 8을 사용합니다.
5. **グループ分け / 무작위 조 편성**을 누르고 프로젝터에 결과를 표시합니다.
6. **もう一度シャッフル / 다시 섞기**로 같은 조건에서 재편성합니다.

상단 **日本語 / 한국어** 버튼으로 즉시 전환할 수 있습니다. 입력한 텍스트, 학생 ID와 출석 상태, 조 개수, 현재 조별 구성과 순서는 그대로 유지됩니다. 언어 설정을 저장하지 않으므로 새로고침하면 일본어로 시작합니다.

**出欠を編集 / 출석 수정**은 기존 출석 상태를 유지합니다. **名簿を編集 / 명단 수정**은 입력 내용을 유지하며 다시 적용하면 전원 출석으로 초기화합니다. 같은 이름도 행마다 다른 학생입니다. 이름을 축약하거나 마스킹하지 않습니다. 무작위 결과는 우연히 이전 결과와 같을 수 있습니다.

## TXT 명단

UTF-8(선택적 BOM 포함), 한 줄에 한 명 형식입니다. 한글·일본어 한자·히라가나·가타카나·혼합 Unicode 이름을 지원합니다. 앞뒤 공백과 빈 행은 무시합니다. 파일은 브라우저 File API로만 읽고 업로드하지 않습니다. 읽을 수 없거나 UTF-8이 아닌 파일은 오류를 표시하며 기존 입력을 유지합니다. 빈 파일은 입력란에 불러올 수 있지만 명단 적용 시 거부됩니다.

CSV/XLSX와 drag & drop은 지원하지 않습니다. 파일은 교수자 본인이 PC에서 관리합니다. 파일 선택기의 기본 버튼·파일명 안내는 브라우저 언어 설정을 따를 수 있습니다.

## 개인정보

입력한 학생 명단은 서버로 전송되거나 저장되지 않으며 현재 브라우저에서만 처리됩니다.

入力した学生名簿はサーバーに送信・保存されず、このブラウザ内でのみ処理されます。

앱은 페이지 메모리만 사용합니다. 서버·DB 저장, localStorage/IndexedDB, 외부 API, CDN, 추적·분석 기능이 없습니다. 새로고침·종료 시 앱 상태가 사라집니다. 정적 호스팅은 앱 파일만 제공하며 명단 입력·파일 읽기·출결·편성·언어 전환에서 앱은 네트워크 요청을 만들지 않습니다.

## 최종 수동 검증

실제 학생 정보 대신 `학생가`, `학생나`, `가나다라마바`, `カキクケコサ`, `あいうえおか`, `가나カナ漢字` 같은 가상 문자열을 사용하세요. 같은 가상 이름을 30행 반복해도 각 행은 독립된 학생입니다.

| 검증 | 기대 결과 |
| --- | --- |
| 30명 / 6조 | 5,5,5,5,5,5명, 데스크톱 3열 × 2행 |
| 30명 / 8조 | 4,4,4,4,4,4,3,3명, 데스크톱 4열 × 2행 |
| 29명 / 6조, 28명 / 6조 | 각각 5,5,5,5,5,4명 / 5,5,5,5,4,4명 |
| 1명 / 1조 | 한 조에 한 명 |
| 30명 / 9조 | 4,4,4,3,3,3,3,3,3명, 무스크롤 여부 확인 |
| 짧은 이름·약 6자 이름 각각 30명 / 6·8조 | 이름 한 줄, 잘림·겹침 없이 모든 카드 표시 |
| textarea / UTF-8 TXT / BOM / CRLF·LF·CR | 같은 파싱 결과, 동명이인 유지 |
| 빈 명단·빈 파일 / 잘못된 확장자·인코딩 / 파일 읽기 실패 | 적절한 오류, 잘못된 파일은 기존 입력 보존 |
| 앞뒤 공백·빈 행 / 한글·한자·가나·혼합 이름 | 공백·빈 행 처리, 이름 손실 없음 |
| 한 명·여러 명 결석 / 전원 결석 | 결석자 제외 / 편성 불가 안내 |
| 출석 수정 후 재편성 / 명단 수정 후 적용 | 출석 변경 반영 / 새 명단·전원 출석 |
| 다시 섞기 | 학생 누락·중복 없음, 인원 차이 최대 1 |
| 조 개수 0·음수·소수·빈 값·출석 인원 초과 | 편성 불가 안내 |
| 최초 접속·새로고침 | 일본어 UI, html lang=ja |
| 일본어 → 한국어 → 일본어 | 입력 원문·출석·ID·조 개수·조별 구성 및 순서 유지, html lang 변경 |
| 오류가 보일 때 언어 전환 | 오류 내용도 선택 언어로 전환 |
| HTML 형태 이름 / 키보드 조작 | 텍스트 그대로 표시 / 주요 조작 가능 |

레이아웃은 두 언어 모두에서 브라우저 콘텐츠 viewport 1280×720, 1366×768, 1920×1080(확대율 100%)으로 확인합니다. 6·8조는 1024×640도 확인하고, 9조는 1280×720 이상에서 확인합니다. 10조 이상은 한 화면 표시를 보장하지 않습니다. 작은 화면·확대 화면·더 긴 이름은 잘리지 않고 줄바꿈·스크롤로 접근할 수 있어야 합니다. 구체적인 절차는 SPEC.md를 참고하세요.

개발자 도구 Network를 열고 초기 앱 파일 로딩을 지운 뒤 입력, TXT 읽기, 출결 변경, 편성, 언어 전환을 수행해 추가 요청이 없는지 확인하세요. Storage에서도 앱이 영구 저장하지 않는지 확인하세요.

## 검증 상태와 배포 준비

2026-09-23 코드 검증: JavaScript 문법 검사, 모의 DOM 기반 257개 검증(양방향 언어 전환과 상태 보존, 기본 편성, 출결, TXT BOM·Unicode·파일 실패), HTML ID·label·상대 자산 경로 검사, 외부 통신·저장 API 부재 검사를 통과했습니다. CSS 수치 검토에서는 지정된 6·8조 viewport 및 1280×720 이상 9조의 높이·6자 이름 폭을 확인했습니다. 테스트 도구나 의존성은 앱에 추가하지 않았습니다.

코드 수준 검증과 실제 브라우저 검증을 구분합니다. 이 작업 환경의 브라우저 도구는 로컬 파일 접근을 차단하므로 실제 렌더링·파일 선택기·Network 확인은 아직 미완료입니다. 사용자에게서 이전 이름 길이 및 9그룹 표시 테스트 통과 결과를 전달받았지만, 최종 일본어 UI와 언어 선택 추가 후에는 위 항목을 재확인해야 합니다. 최종 브라우저 검증 통과 전에는 배포 완료로 간주하지 않습니다.

현재 Git 원격 저장소가 없고 `gh` CLI 및 저장소 생성·Pages 설정 도구가 없어 원격 생성·push·활성화는 수행하지 않았습니다. 사용자가 최종 브라우저 검증 후 아래 순서로 배포할 수 있습니다.

1. GitHub에서 **kumiwake-kun** 저장소를 만듭니다. 개인 무료 플랜의 Pages를 사용할 경우 공개 저장소로 만듭니다. README 자동 생성 없이 빈 저장소로 시작합니다.
2. 이 프로젝트의 상위 폴더에서 다음 명령을 실행합니다. `YOUR_ACCOUNT`를 본인 계정명으로 바꾸고 Git 인증 요청을 완료하세요.

```sh
git add group-maker/index.html group-maker/style.css group-maker/app.js group-maker/README.md group-maker/SPEC.md
git commit -m "Release Kumiwake-kun v0.1"
git branch -M main
git remote add origin https://github.com/YOUR_ACCOUNT/kumiwake-kun.git
git push -u origin main
```

3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, **main**, **/(root)**를 선택하고 저장합니다.
4. Pages 배포가 성공하면 `https://YOUR_ACCOUNT.github.io/kumiwake-kun/group-maker/`에 접속합니다. 기존 `group-maker/` 폴더 구조를 유지하므로 URL에 이 경로가 포함됩니다. CSS/JS는 `style.css`, `app.js` 상대 경로를 사용합니다.
5. 게시된 주소에서 최초 일본어 표시, 두 언어 전환, TXT 읽기, 6·8조 표시와 Network를 다시 확인합니다.

커밋 대상은 위 5개 앱·문서 파일뿐입니다. 실제 학생 명단이나 사용자 TXT 파일을 저장소에 추가하지 마세요.
